Canteen Connect

Project Overview

Canteen Connect is a web-based food ordering system designed to simplify food ordering and order management in a college canteen.

Students can view available food items, search the menu, add items to their cart, select their table number or parcel option, and place orders.

Technologies Used

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Maven

Main Features

- Food menu display
- Food category selection
- Search functionality
- Shopping cart
- Student name and table number entry
- Online order placement
- Canteen dashboard
- Order status management

Project Structure

The complete source code is provided in "CanteenConnect.zip".

How to Run

1. Install Java 17 or later.
2. Install MySQL.
3. Configure the database in "application.properties".
4. Import the database using "database/schema.sql".
5. Run the Spring Boot application using Maven.
